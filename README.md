# Projection Cue Player

撮影現場で迷わず使える、プロジェクター用の動画キュー再生アプリです。

VJソフトのような高機能な演出ツールではなく、「動画を選ぶ」「フルスクリーンにする」「Space / Enter / クリックで再生する」ことに絞っています。

## 一般ユーザー向け

### このアプリでできること

- ローカルの動画ファイルを1本選んで再生できます。
- 動画はアップロードされません。選んだPCのブラウザ内だけで再生します。
- 再生前は動画の先頭へ戻って待機します。表示は黒背景または1コマ目から選べます。
- Space / Enter / クリック / タップで再生できます。
- 再生が終わると、自動で動画の最初に戻って待機します。
- 再生前の遅延、左右反転、表示方法（contain / cover）、待機画面を設定できます。
- 音声認識をONにすると、設定したウェイクワードでも再生できます。
- ユーザーが許可した場合、Vosk日本語モデルをブラウザに保存してオフライン音声認識できます。
- 対応ブラウザでは、PWAとしてPCにインストールできます。

### 想定ユースケース

- コスプレ撮影で、背景動画や演出動画をプロジェクターに出す
- 小規模スタジオで、PC係がいなくても決まった動画をキュー再生する
- 展示やイベントで、合図に合わせて動画を1回だけ再生する
- カメラマンや出演者が、フットスイッチやキーボードで再生する

### 使い方

1. 公開されたアプリのURLを開きます。
2. 「動画ファイルを選択」から動画を選ぶか、画面にドラッグ&ドロップします。
3. 必要なら「左右反転」「再生遅延（秒）」「待機画面」などを設定します。
4. 必要なら「音声トリガー設定」を開き、音声認識をONにします。
5. オフラインで音声認識したい場合は「Voskモデルを保存」を押し、確認画面で許可します。
6. 必要なら「フルスクリーン開始」を押します。
7. Space / Enter / クリック / タップ、またはウェイクワードで再生します。
8. 再生後は自動で最初に戻り、次の合図を待ちます。

### キーボードショートカット

| 操作 | 内容 |
| --- | --- |
| Space | 再生トリガー |
| Enter | 再生トリガー |
| Esc | 遅延中はキャンセル、再生中は停止して先頭へ戻る |
| F | フルスクリーン切り替え |
| M | 左右反転切り替え |

入力欄に文字を入れているときは、SpaceやEnterで誤って再生しにくいようにしています。

### 表示オプション

- 画面下部情報: デフォルトOFF。ONにすると動画選択状況、左右反転、表示方法を投影画面下部に表示します。
- 待機画面: デフォルトは黒背景。必要に応じて1コマ目表示に切り替えられます。
- 遅延カウント表示: デフォルトON。OFFにすると遅延中もカウント数字を出しません。

### インストールとオフライン対応

ChromeやEdgeなどの対応ブラウザでは、アドレスバー付近のインストールボタンやブラウザメニューからアプリとしてインストールできます。

Service Workerにより、アプリ本体のHTML/CSS/JSは再訪時に読み込みやすくなります。動画ファイルは保存しないため、アプリを開き直したときは毎回ユーザーが動画を選択してください。

音声認識をオフラインで使いたい場合は、音声トリガー設定内の「Voskモデルを保存」を押してください。確認画面で許可した場合だけ、大きなVosk日本語モデルをこのブラウザに保存します。

### よくあるトラブル

#### 動画が再生されない

- mp4またはwebmなど、ブラウザで再生できる動画を選んでください。
- 動画ファイルが壊れていないか確認してください。
- 音声付き動画を遅延再生する場合、ブラウザの自動再生制限で失敗することがあります。その場合は遅延を0秒にして試してください。

#### フルスクリーンにならない

- ブラウザやOSがフルスクリーンを許可しているか確認してください。
- 別ウィンドウや別ディスプレイに出す場合は、先にブラウザウィンドウを目的の画面へ移動してください。

#### 音が出ない

- PC本体、ブラウザタブ、プロジェクターや外部スピーカーの音量を確認してください。
- 一部ブラウザでは、ユーザー操作なしの音声再生が制限されます。

#### スペースキーが効かない

- 入力欄にカーソルがある場合は、画面の動画プレビュー部分を一度クリックしてから試してください。
- フットスイッチを使う場合は、SpaceまたはEnterを送る設定にしてください。

#### 音声認識が使えない

- ブラウザでマイク権限を許可してください。
- Voskを使う場合は、開発者向け手順に従って日本語モデルを配置してください。
- Voskモデルをブラウザに保存していない場合、オンライン時はChromeやEdgeなどでWeb Speech APIへ切り替わることがあります。
- オフラインで使う場合は、事前に「Voskモデルを保存」を実行してください。
- Space / Enter / クリック / タップでの操作は音声認識なしで使えます。

### 主要コンポーネント

- `src/App.tsx`: 動画選択、状態管理、再生トリガー、フルスクリーン、設定保存、ログ表示
- `src/services/voiceTrigger.ts`: Vosk優先、Web Speech APIフォールバックの音声トリガーサービス
- `public/sw.js`: アプリ本体のキャッシュ用Service Worker
- `public/manifest.webmanifest`: PWAインストール用Manifest

### 状態管理

動画キューの状態は以下に集約しています。

- `no-video`: 動画未選択
- `idle`: 1コマ目で待機中
- `delay`: 再生遅延カウント中
- `playing`: 再生中
- `ended`: 再生終了後、先頭に戻って待機中
- `error`: エラー表示中

ボタン、Space、Enter、クリック、タップ、音声入力は、同じ `triggerPlayback()` を通る構造です。再生中または遅延中の追加トリガーは無視します。

待機中の動画は内部的には常に先頭へ戻します。表示だけを黒背景または1コマ目表示に切り替えるため、再生開始時の挙動は同じです。

### Vosk日本語モデルの配置

Voskを使う場合は、以下のファイルを配置してください。

```text
public/vosk/vosk-model-small-ja-0.22.tar.gz
```

このリポジトリでは、公式の `vosk-model-small-ja-0.22.zip` をブラウザ用に `model/` ルートの `.tar.gz` へ変換して配置します。アプリはユーザーが「Voskモデルを保存」を押して許可した場合だけ、このモデルをCache Storageへ保存します。

モデルファイルがない場合、対応ブラウザではWeb Speech APIへフォールバックします。動画ファイルはService Workerでキャッシュしません。
