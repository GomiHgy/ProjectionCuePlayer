# Projection Cue Player

撮影現場で迷わず使える、プロジェクター用の動画キュー再生アプリです。

VJソフトのような高機能な演出ツールではありません。「動画を選ぶ」「撮影モードにする」「Space / Enter / クリックで再生する」ことに絞っています。

開発者向けのセットアップやデプロイ手順は [README.dev.md](README.dev.md) を見てください。

## できること

- ローカルの動画ファイルを1本選んで再生できます。
- 選択した動画はアップロードされません。PCのブラウザ内だけで再生します。
- 再生前は動画の先頭へ戻って待機します。
- 待機中の表示は黒背景または動画の最初の画面から選べます。
- Space / Enter / クリック / タップで再生できます。
- 再生が終わると、自動で動画の最初に戻って待機します。
- 再生遅延、左右反転、全体表示 / 画面いっぱいを設定できます。
- 「声で再生」をONにすると、設定したウェイクワードでも再生できます。
- オフライン音声認識を準備すると、ネットがない場所でも声で再生しやすくなります。
- 対応ブラウザでは、PCにアプリのようにインストールできます。

## 想定ユースケース

- コスプレ撮影で、背景動画や演出動画をプロジェクターに出す
- 小規模スタジオで、PC係がいなくても決まった動画をキュー再生する
- 展示やイベントで、合図に合わせて動画を1回だけ再生する
- カメラマンや出演者が、フットスイッチやキーボードで再生する

## 使い方

1. 公開されたアプリのURLを開きます。
2. 「動画ファイルを選択」から動画を選ぶか、画面にドラッグ&ドロップします。
3. 必要なら「左右反転」「再生遅延（秒）」「待機中の表示」などを設定します。
4. 必要なら「声で再生」を開き、声で再生をONにします。
5. オフラインで音声認識したい場合は「オフライン準備」を押し、確認画面で許可します。
6. 「撮影モードへ」を押します。
7. Space / Enter / クリック / タップ、またはウェイクワードで再生します。
8. 再生後は自動で最初に戻り、次の合図を待ちます。

## 推奨PCスペック

最低目安:

- Chrome / Edge の最新版
- CPU: 4コア以上
- メモリ: 8GB以上
- 動画: H.264 MP4 / 1920×1080 / 30fps程度
- GPU: H.264などの動画再生支援が使える内蔵GPUまたは外部GPU

推奨スペック:

- CPU: Intel Core i5 第8世代 / Ryzen 5 3000 相当以上
- メモリ: 16GB以上
- 動画: H.264 MP4 / 1920×1080 30〜60fps
- 4K動画: 6〜8コア以上、16GB以上、4K再生支援のあるGPU
- 保存先: SSD上の動画ファイル

アプリ内の「PCスペック目安」では、ブラウザから取得できるCPUコア数、メモリ目安、動画形式、選択動画の解像度をもとに注意表示を出します。CPU世代やGPUの動画再生支援はブラウザから正確に取得できないため、撮影前に実際の動画を撮影モードで通し再生してください。

## キーボードショートカット

| 操作 | 内容 |
| --- | --- |
| Space | 再生トリガー |
| Enter | 再生トリガー |
| Esc | 遅延中はキャンセル、再生中は停止して先頭へ戻る |
| F | 撮影モード切り替え |
| M | 左右反転切り替え |

入力欄に文字を入れているときは、SpaceやEnterで誤って再生しにくいようにしています。

## 表示オプション

- 投影画面の情報: デフォルトOFF。ONにすると動画選択状況、左右反転、動画の表示設定を投影画面下部に表示します。
- 待機中の表示: デフォルトは黒背景。必要に応じて動画の最初の画面に切り替えられます。
- 遅延カウント表示: デフォルトON。OFFにすると遅延中もカウント数字を出しません。
- 簡易ログ: 通常は折りたたまれています。必要なときだけ開いて確認できます。

## インストールとオフライン対応

ChromeやEdgeなどの対応ブラウザでは、アドレスバー付近のインストールボタンやブラウザメニューからアプリとしてインストールできます。

アプリ本体は再訪時に読み込みやすくなります。動画ファイルは保存しないため、アプリを開き直したときは毎回ユーザーが動画を選択してください。

音声認識をオフラインで使いたい場合は、声で再生の設定内にある「オフライン準備」を押してください。確認画面で許可した場合だけ、大きな音声認識データをこのブラウザに保存します。

## よくあるトラブル

### 動画が再生されない

- mp4またはwebmなど、ブラウザで再生できる動画を選んでください。
- 動画ファイルが壊れていないか確認してください。
- 音声付き動画を遅延再生する場合、ブラウザの自動再生制限で失敗することがあります。その場合は遅延を0秒にして試してください。

### 撮影モードにならない

- ブラウザやOSがフルスクリーンを許可しているか確認してください。
- 別ウィンドウや別ディスプレイに出す場合は、先にブラウザウィンドウを目的の画面へ移動してください。

### 音が出ない

- PC本体、ブラウザタブ、プロジェクターや外部スピーカーの音量を確認してください。
- 一部ブラウザでは、ユーザー操作なしの音声再生が制限されます。

### スペースキーが効かない

- 入力欄にカーソルがある場合は、動画プレビュー部分を一度クリックしてから試してください。
- フットスイッチを使う場合は、SpaceまたはEnterを送る設定にしてください。

### 音声認識が使えない

- ブラウザでマイク権限を許可してください。
- オフライン準備をしていない場合、対応ブラウザではブラウザ標準の音声認識へ切り替わることがあります。
- オフラインで使う場合は、事前に「オフライン準備」を実行してください。
- Space / Enter / クリック / タップでの操作は音声認識なしで使えます。
